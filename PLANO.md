## Estrutura do Site

### Páginas/Seções (Single Page Application)
1. **Hero/Capa** - Nomes do casal, data do casamento, foto principal
2. **Nossa História** - Timeline do relacionamento com fotos
3. **Cerimônia & Festa** - Data, horário, local com mapa integrado
4. **Galeria de Fotos** - Fotos do casal em grid responsivo
5. **Lista de Presentes** - Links para lojas ou informações de PIX/conta bancária
6. **Mensagem Final** - Agradecimento e contagem regressiva

## Arquitetura Técnica

### Arquivos a Criar
```
/index.html          - Estrutura HTML principal
/css/
  style.css          - Estilos principais
  responsive.css     - Media queries para mobile
/js/
  main.js            - Interações e animações
  countdown.js       - Timer de contagem regressiva
/images/             - Pasta para fotos (placeholder inicialmente)
/fonts/              - Fontes elegantes para casamento
```

### Recursos Técnicos
- **Design Responsivo**: Mobile-first (essencial para WhatsApp)
- **Scroll Suave**: Navegação entre seções
- **Lazy Loading**: Carregamento otimizado de imagens
- **Meta Tags OG**: Preview bonito ao compartilhar no WhatsApp
- **Contagem Regressiva**: Dias/horas até o casamento
- **Google Maps Embed**: Localização da cerimônia/festa

### Estilo Visual
- **Cor Principal**: Dourado (#D4AF37) - detalhes, bordas, ícones
- **Cor Secundária**: Verde Sage (#9CAF88) - fundos, acentos
- **Neutros**: Branco (#FFFFFF), Off-white (#FAF9F6), Cinza suave
- Tipografia romântica para títulos + legível para texto
- Animações sutis ao scroll
- Design clean e moderno
